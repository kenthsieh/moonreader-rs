# MoonReader(月讀)— Rust 桌面版

以 Rust + [egui](https://github.com/emilk/egui) 改寫自 Android Compose app 的**純文字(TXT)閱讀器 + 分頁編輯器**,專為中文長篇小說設計:數十 MB 的大檔可順暢捲動、搜尋、編輯並安全存回原編碼。

## 功能總覽

### 書庫

- 以檔案對話框加入 `.txt` / `.text` 檔(Markdown 不支援,會提示改選 TXT)。
- 每本書顯示標題、偵測到的編碼與檔案大小;可「打開」或「移除」(只移出書庫,不刪檔)。
- 命令列傳入檔案路徑時自動加入書庫並直接開啟:`moonreader-rs 小說.txt`。
- 記住每本書的上次閱讀位置、編碼、檔案指紋與最後開啟時間。

### 閱讀

| 功能 | 說明 |
|---|---|
| 大檔虛擬化 | 只排版可見段落;段落高度先估算、畫過即以實際排版高度校正 |
| 點按手勢 | 左側 30% 上一頁、右側 30% 下一頁、中央 40% 開關控制面板 |
| 翻頁 | 一次捲動一個畫面高,保留一行重疊 |
| 長按(≥0.45 秒) | 設定/取消「編輯定位段」(以底色標示),進入編輯器時從該處開始 |
| 位置記憶 | 停止捲動 0.5 秒後自動寫回;返回書庫或關閉視窗時也會寫回 |
| 進度 | 依全書字元位置顯示百分比;控制面板的拉桿可直接跳轉 |
| 章節目錄 | 自動擷取章節,目前章節以勾號標示,開啟時自動捲到目前章節;頂欄顯示目前章節名 |
| 全文搜尋 | 背景執行緒掃描、輸入 0.25 秒後才開始;英數不分大小寫;最多 5000 筆(超過顯示 `+`);↑/↓ 切換並高亮 |
| 排版設定 | 主題(明亮/夜間/米色)、字型大小 12–40、行距 1.0–2.2、段落間距 0–40、左右邊距 0–48、靠左/左右對齊;設定會保存 |
| 重新以其他編碼開啟 | 自動偵測錯誤時,可手動改以 UTF-8 / UTF-16LE / UTF-16BE / Big5 / GBK / windows-1252 重開 |

**章節偵測規則**:獨立一行,且(忽略行首全形縮排)符合以下任一格式:

- `第` + 數字或中文數字(〇零一二三四五六七八九十百千萬兩)+ `章/回/節/集/部/卷/篇`,例如「第一章」、「第 3 回」、「第二百三十六回」
- `Chapter` + 阿拉伯或羅馬數字(不分大小寫),例如「Chapter 12」、「CHAPTER IV」

### 編輯

| 功能 | 說明 |
|---|---|
| 分頁編輯 | 全文切成每頁最多 60,000 字的編輯頁(盡量切在換行處),一次只載入一頁;頁碼列可上一頁/下一頁/輸入頁碼跳頁 |
| 復原/重做 | 頁級歷史,最多 60 步,可跨頁、跨存檔;停止輸入 0.45 秒後記一步 |
| 本頁搜尋 | 不分大小寫(英數)、高亮全部命中,↑/↓ 切換並選取命中文字;打字時自動重算 |
| 存檔編碼 | 下拉選單選擇存檔編碼(只影響寫回,不重新解碼目前內容) |
| 未存檔提示 | 標題顯示「●未存檔」;返回閱讀或關閉視窗時詢問「儲存 / 不儲存,直接離開 / 取消」 |
| 存檔後 | 存檔成功自動返回閱讀畫面並重新載入 |

**快捷鍵(編輯器)**

| 按鍵 | 動作 |
|---|---|
| `Ctrl+S` | 存檔 |
| `Ctrl+Z` | 復原 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+F` | 本頁搜尋 |

### 安全存檔

1. **外部修改衝突偵測**:存檔前重讀磁碟並比對 SHA-256 指紋;若檔案在編輯期間被其他程式改過,會詢問「覆蓋(先備份外部版)/ 改用外部版 / 取消」,絕不默默蓋掉。
2. **自動備份**:每次覆寫前,把磁碟上的現況備份到備份目錄,檔名為 `<原檔名>.<yyyyMMdd_HHmmss>.bak`(同一秒內重複存檔會加序號,不會互蓋)。
3. **原子寫入**:先寫同目錄暫存檔並 fsync,再 rename 取代原檔;寫到一半當機或斷電時,原檔仍完整。書庫與偏好設定檔也採同樣方式寫入。
4. **編碼保真**:
   - 原檔有 UTF-8 BOM 時保留;UTF-16 一律寫入 BOM,確保重開時能正確辨識。
   - 文字含目標編碼無法表示的字元(例如以 Big5 存 emoji)時**拒絕存檔**,並列出是哪些字元,請改選 UTF-8 等編碼後再存,不會被替換成 `&#NNNN;`。

### 編碼偵測

依序判斷,取第一個成立者:

1. BOM:UTF-8 / UTF-16LE / UTF-16BE
2. 整份檔案能以 UTF-8 無錯解碼 → UTF-8(含純 ASCII)
3. Big5 無錯解碼 → Big5
4. GBK 無錯解碼 → GBK(以 GB18030 處理,為 GBK 超集)
5. 後備 windows-1252(任何位元組都能解)

> 簡體 GBK 檔有時也能被 Big5 無錯解碼而誤判;遇到亂碼時請用「重新以其他編碼開啟」選 GBK。

## 建置與執行

需要 Rust 工具鏈(以 rustc 1.99 測試)。

```bash
cargo run --release
```

```bash
cargo run --release -- "D:/小說/某本書.txt"
```

```bash
cargo test
```

> **平台**:目前只會從 `C:/Windows/Fonts` 載入中文字型(依序嘗試等線 DengXian、Noto Serif/Sans TC、微軟雅黑、宋體 SimSun,取第一個存在者),因此中文顯示只支援 Windows。Linux/macOS 可以編譯執行,但中文會顯示為方塊。

## 資料存放位置

| 平台 | 路徑 |
|---|---|
| Windows | `%APPDATA%\example\moonreader\data\MoonReader\` |
| Linux | `~/.local/share/moonreader/MoonReader/` |
| macOS | `~/Library/Application Support/com.example.moonreader/MoonReader/` |

目錄內容:

- `library.json`:書庫清單(含閱讀位置、編碼、指紋)。若檔案損毀無法解析,會改名為 `library.json.corrupt-<時間>` 保留,並以空書庫啟動。
- `reader_prefs.json`:閱讀排版設定。
- `backups/`:存檔前的自動備份。

## 專案結構

```
src/
├── main.rs              進入點(視窗設定)
├── lib.rs               模組根(供 main 與 tests 共用)
├── app.rs               egui UI:書庫 / 閱讀 / 編輯三個畫面、手勢、對話框、背景工作
├── model.rs             資料模型:Book、ReaderPrefs、LoadResult、SaveOutcome
├── repo.rs              BookRepository:載入、衝突偵測、備份、原子寫回、備份清單與還原
├── store.rs             書庫與偏好設定的 JSON 持久化
├── encoding.rs          編碼偵測、解碼、存檔用編碼(BOM、無法表示字元檢查)
├── fileio.rs            檔案讀寫(原子寫入)、SHA-256 指紋、修改時間
├── toc.rs               章節目錄擷取
└── text/
    ├── chunker.rs       依行切段落(超過 2000 字再切塊),附原文位元組 offset
    ├── page_splitter.rs 編輯分頁切割與字元位置換算
    ├── page_history.rs  頁級復原/重做歷史
    ├── search.rs        位元組級全文搜尋(大檔不複製整份字串)
    └── undo_redo.rs     快照式復原堆疊(移植保留,UI 未使用)
tests/
└── data_layer.rs        資料層整合測試:讀寫、編碼往返、衝突、備份/還原、原子寫入、持久化
```

## 已知限制

- 中文字型只支援 Windows(見上方「平台」)。
- 備份清單與還原已實作於 `BookRepository::list_backups` / `restore_backup` 並有測試,但尚未提供 UI 入口;需要還原時可直接從 `backups/` 目錄取回檔案。
- 閱讀畫面的全文搜尋只對英數字母不分大小寫;其他文字(如帶重音的拉丁字母)須完全相符。
- 存檔是在 UI 執行緒同步進行,超大檔案存檔時畫面會短暫停頓。
